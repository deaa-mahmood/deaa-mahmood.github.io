# Portfolio Website Plan for Deaa Mahmood

## Project Overview
- **Project Name**: Deaa Mahmood Portfolio
- **Type**: Single-page personal portfolio website
- **Core Functionality**: Professional portfolio showcasing IT Support/Python Developer skills, projects, and contact info
- **Target Users**: Potential employers, clients, and professional contacts

## Files to Create
1. **index.html** - Main HTML structure with all 6 sections
2. **styles.css** - Dark theme styling with glassmorphism effects
3. **script.js** - Animations and interactive functionality

## Design Specifications

### Color Palette
- Primary Background: #0a0a0f (deep black)
- Secondary Background: #0d1117 (dark blue-black)
- Accent Color: #00d4ff (cyan glow)
- Secondary Accent: #7c3aed (purple)
- Text Primary: #ffffff
- Text Secondary: #a0a0a0
- Glass Effect: rgba(255, 255, 255, 0.05)

### Typography
- Font Family: 'Poppins' for headings, 'Inter' for body
- Hero Name: 4rem (64px)
- Section Titles: 2.5rem (40px)
- Body Text: 1rem (16px)

### Sections to Implement
1. **Navigation** - Fixed header with smooth scroll links
2. **Hero Section** - Name, title, intro, CTA buttons
3. **About Me** - Professional summary
4. **Skills** - Animated progress bars/cards for each skill
5. **Projects** - 4 project cards with hover effects
6. **Certifications** - Certificate cards
7. **Contact** - Contact form and social links

### Animations & Effects
- Smooth scroll navigation
- Fade-in animations on scroll (Intersection Observer)
- Glowing button effects with box-shadow
- Glassmorphism cards with backdrop-filter
- Progress bar animations
- Hover effects on cards and buttons

### Responsive Breakpoints
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px
